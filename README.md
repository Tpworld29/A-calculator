# My First Calculator 

## About

This is my first project for Hack Club Phantom.

I'm new to Phantom, so I wanted to start with something simple and learn how things work. I chose to make a calculator using HTML, CSS and JavaScript.

I'm still learning web development, and this is my first step. I made this project to practise coding, fix mistakes and understand how to build a website.

## Languages used

- HTML
- CSS
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimal numbers
- Clear and delete buttons
- Keyboard support
